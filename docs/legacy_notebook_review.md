## หลักฐานที่นำไปใช้ต่อได้

- แสดงโครงคอลัมน์และชื่อไฟล์เดิมของ Trends, YouTube และ Play Store
- มีภาพกราฟสี่ชุดใน cell index 45: Trends, average video views, review rating และ review volume

## การเก็บไฟล์และสิทธิ์เข้าถึง

พบ connection string ที่ฝัง credential ใน cell index 24 จึงเพิ่มชื่อ notebook นี้ใน `.gitignore` และไม่คัดลอก credential ลงรายงาน ไม่ได้ทดสอบการเข้าสู่ฐานข้อมูล และไม่ได้แก้ไฟล์ต้นฉบับ เจ้าของบัญชีควรเปลี่ยน credential ก่อนแชร์เวอร์ชันนั้นอีก

## ขอข้อมูลจากเพื่อนให้ตรงเวอร์ชัน

ขอ notebook/collector ล่าสุดหลังย้ายไป Firestore พร้อม CSV หรือ JSON ของข้อมูลจริง และวันเก็บ/ช่วงเวลา/ขอบเขตช่องหรือภาษา ไม่ต้องขอ credential

ชื่อ CSV ที่เวอร์ชันเก่าใช้ทำกราฟเป็นแนวทางค้นไฟล์ ไม่ใช่การยืนยันว่าเวอร์ชันล่าสุดยังใช้ชื่อนี้:

1. `rovmlbbGoogleTrends.csv`
2. `mlbb_before_aug2025.csv`
3. `mlbb_after_aug2025.csv`
4. `rov_before_aug2025.csv`
5. `rov_after_aug2025.csv`
6. `mlbbplay.csv`
7. `rovplay.csv`

ข้อมูล YouTube/รีวิวเก่ามีโอกาสนำเข้าได้เมื่อยืนยัน schema และที่มา ส่วน Trends ที่ถูกต่อจากหลาย query window ต้องตรวจวิธี normalize ก่อนใช้เปรียบเทียบข้ามเวลา แม้ export สำเร็จแล้วก็ตาม
