1. ยืนยันช่วงศึกษาและคำถามหลัก โดยเฉพาะว่าจะวิเคราะห์ก่อน–หลังสิงหาคม 2025 ตามงานเดิมหรือไม่
2. ได้ YouTube export ที่มีวันเก็บยอดวิว หรือใช้ API key ของเจ้าของโปรเจกต์เก็บใหม่ภายใต้กลุ่มช่องที่ประกาศ
3. ตรวจช่วงเวลาและวิธีเลือกรีวิวให้เทียบกันได้ พร้อมเปิดเผยช่องว่างที่ยังเหลือ
